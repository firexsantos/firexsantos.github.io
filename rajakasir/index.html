Fitur

Semua yang dibutuhkan toko, dalam satu aplikasi

Dari meja kasir sampai gudang, dari pembelian ke supplier sampai laporan laba — tanpa berlangganan, tanpa ribet.

Manajemen barang

Puluhan ribu barang, tetap lancar

  • Filter lengkap: kategori, supplier, lokasi rak, stok menipis, kedaluwarsa, margin
  • Ubah harga banyak barang sekaligus dengan pratinjau, riwayat harga tersimpan
  • Satuan dus / pak dengan barcode sendiri, harga grosir bertingkat & harga member
  • Cetak label barcode untuk stiker A4 atau printer label
  • Pindah dari aplikasi kasir lama: impor backup MySQL (.sql) atau Excel

Pertanyaan yang sering diajukan

Apakah data toko saya aman?

Ya. Data disimpan di komputer Anda sendiri (atau server database milik Anda). Raja Kasir tidak mengirim data usaha Anda ke kami. Backup otomatis harian dan backup saat aplikasi ditutup tersedia di dalam aplikasi.

Apakah butuh internet?

Tidak untuk berjualan. Internet hanya dipakai untuk mengunduh pembaruan.

Database apa yang didukung?

SQLite (otomatis, tanpa server — cocok untuk satu komputer), MySQL / MariaDB, atau PostgreSQL untuk beberapa komputer kasir yang memakai data yang sama.

Apakah pembaruan menghapus data?

Tidak. Pembaruan hanya mengganti program; data tersimpan terpisah dan dicadangkan otomatis bila struktur database perlu ditingkatkan.

Saya memakai aplikasi kasir lama. Bisa pindah?

Bisa. Raja Kasir mengimpor backup MySQL (.sql) aplikasi kasir lama dan daftar barang Excel (.xlsx / .csv), lengkap dengan pratinjau sebelum data disimpan.

Komputer saya rusak atau install ulang, bagaimana lisensinya?

Hubungi kami dengan nomor seri lisensi lama dan ID Perangkat baru untuk penggantian key, sesuai ketentuan perjanjian lisensi.

Perangkat apa saja yang didukung?

Printer struk thermal 58 / 76 / 80 mm, printer biasa untuk laporan A4 / F4, scanner barcode (USB), laci kas yang tersambung ke printer struk, dan printer label.
